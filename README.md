## 安装

1. 在 Chrome、Edge 或 Firefox 安装 Tampermonkey（油猴）。
2. 打开 Tampermonkey 管理面板，选择“添加新脚本”。
3. 点击上方“安装最新版脚本”，由 Tampermonkey 确认安装。
4. 打开游戏网站；如果页面原本已经开着，请按 `Ctrl + Shift + R` 强制刷新。

安装成功后，游戏左下角会出现红色“中”按钮。

## 已覆盖内容

- 当前游戏版本的 708 个官方界面键：设置、背包、装备、强化、任务、商店、邮箱、队伍、好友、团队副本、新手教程、系统提示等。
- 403 个游戏内容键：物品、技能、任务、怪物、区域、商店和抽取内容。
- 中文文案经过本地化润色，并统一角色名、货币名、强化格式、标点和界面术语。
- 同时识别游戏自带的韩文、英文和日文原文，因此不强制更改你原有的游戏语言。
- 动态 DOM 界面使用增量监听翻译；Canvas 文字会在测量和绘制时同步翻译，可覆盖大部分世界名牌和由 Canvas 生成的文字纹理。
- 任务列表中拼接显示的“任务名 — 描述 ｜ 进度”会按段翻译，兼容每日、每周和常驻任务的动态进度数字。
- 技能冷却等高频更新文字会在写入页面前同步翻译，避免“秒/초”来回闪烁。
- 翻译只修改浏览器里的显示结果，不修改 WebSocket、游戏数值、战斗逻辑或服务器请求。

## “中”按钮设置

- “启用中文翻译”：控制后续翻译。关闭后刷新页面，可完整恢复游戏原文。
- “源语言设为韩语”：兼容选项。正常情况下无需使用；如果某些界面因异常语言设置未被识别，可以点一次并让页面刷新。
- “重新扫描”：游戏更新界面后可手动重试。

## 版本基准
